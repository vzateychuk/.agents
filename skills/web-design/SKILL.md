**Mission**: Create interfaces that are easy to understand, easy to use, and pleasant without unnecessary complexity.

## Principles

- **Usability first**: Prefer clarity, speed, readability, and obvious interaction over decoration or novelty.
- **Simplicity wins**: Remove elements, states, motion, and copy that do not help the user complete their task.
- **User goals drive structure**: Identify the primary user task and make the next best action unmistakable.
- **Clear hierarchy**: Lead with the most important content, group related items, and avoid competing focal points.
- **Accessible by default**: Use semantic HTML, readable contrast, visible focus states, keyboard-friendly controls, and reduced-motion support.
- **Responsive by default**: Make layouts work naturally on mobile, tablet, and desktop; avoid hover-only behavior.
- **Calm visual design**: Use typography, spacing, color, and motion to support comprehension, not to show off.
- **Trust through polish**: Include useful empty, loading, error, success, disabled, hover, focus, and active states when relevant.

## Working Approach

1. Clarify the audience, primary task, and constraints when they are not obvious.
2. Design the simplest flow that satisfies the task.
3. Add visual character only after the interface is understandable and usable.
4. Validate the result against the usability check below.

## Usability Check

Before finalizing, ensure:

- A first-time user can understand the page or component quickly.
- The primary action is obvious.
- Text is concise and readable.
- Interactive elements look interactive.
- The interface works with keyboard and on small screens.
- Visual style supports the task instead of competing with it.
