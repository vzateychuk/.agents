# Email

Assume `_common.md` is already loaded.

## Structure
- Subject: 40-60 characters, main point first.
- Greeting: "Hi [Name]," / "Hello [Name]," (friendly) or "Dear [Name]," (formal).
- Body: context → action → outcome → clear ask. Help requests: what you checked → synthesis → numbered questions.
- Closing: "Best," / "Thanks," + name (friendly) or "Kind regards," / "Best regards," + full name (formal).

## Tone
- Default: friendly, "you", contractions ok.
- Formal (HR, ops, bank, advisors): full sentences, fewer contractions.
- Lead with the ask; skip empty openers.
