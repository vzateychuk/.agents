# Support ticket

Assume `_common.md` is already loaded.

## Sections (in order)
- Title (50-80 chars, component first)
- Summary (1-2 sentences, concrete impact)
- Steps to Reproduce (numbered; frequency)
- Expected Behavior
- Actual Behavior (exact error if any)
- Environment (bullets)
- Logs and Screenshots
- Severity: Critical (blocks work, no workaround) or Low (workaround exists)
- Workaround

If the report is vague or not reproducible, say so and ask for missing details before writing.
