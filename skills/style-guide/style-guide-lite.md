# Style guide (lite)

- Always English. No emojis. Prefer bullets over tables.
- Short paragraphs (2-4 sentences). Plain text when possible.
- Expand or avoid abbreviations.
- Oxford comma. Digits for 10+, versions, percentages, measurements.
- Sentence case headings. Gender-neutral pronouns unless the person is known.
- No AI traces. Clear and direct.
- Email / messenger: no `**` bold; use labels, line breaks, lists.
- Email: subject 40-60 chars; greeting; context → action → ask; closing + name.
- Messenger: main point first; under ~80 words; one idea per line.
- Techdocs: imperative steps; Problem → Result → Root cause for failures; code blocks for commands.
- Support: Title, Summary, Steps, Expected, Actual, Environment, Severity, Workaround.
