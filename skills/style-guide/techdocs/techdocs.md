# Tech docs

Assume `_common.md` is already loaded.

- Imperative how-to steps. Outcome-focused headings.
- State target scenarios early (who / where).
- How-to: numbered steps. Failures: Problem → Result → Root cause.
- Code blocks for commands, paths, errors. Expand acronyms on first use.
- Non-English draft: translate to English first, then apply style.
